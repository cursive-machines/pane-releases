## Pane: minimal, aesthetic file manager with comfortable UI

## Download

Head to the [Releases](../../releases) page and download the latest `Pane_X.Y.Z_x64-setup.exe` installer.

**Requirements:** Windows 10 or 11, x64.

## Features

**Four view modes**
- List — tabular view with resizable Name / Type / Date / Size columns, virtual scrolling for large folders
- Grid — icon grid
- Columns — macOS Finder-style hierarchical columns
- Tree — expandable/collapsible folder tree

**Tabs** — open multiple locations at once, drag to reorder, state persists across sessions

**Navigation** — address bar, back/forward/up history, mouse back/forward buttons (XButton1/2)

**Sidebar** — quick access to drives, Desktop/Downloads/Documents/Pictures, storage usage widgets

**Details panel** — toggleable right panel showing name, type, size, path, dates

**Folder sizes** — optional recursive size calculation with SQLite cache (24 h expiry)

**Settings** — backdrop opacity, font family & size, alternating rows, folder size toggle
